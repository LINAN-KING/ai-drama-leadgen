## Current Runtime Receipt

- Automated suite: the final default `npm test` gate passed 37 test files and 181 tests on Windows with no failures or skipped tests.
- Real E2E: `39.966016` seconds, `1080x1920`, H.264/AAC, 30 fps, all hard QA passed.
- Alignment: `coverage=1`, `substitutionRate=0`, `medianTimingResolutionMs=90`.
- Audio: narration `-16 LUFS`; final mix `-14.4 LUFS`; true peak `-4 dBTP`.
- Actual fallback: Edge was requested, failed on a sentence after bounded retries, and the entire video was regenerated with MiMo; the report records both requested and actual providers.
- Package verification builds through `prepack`; the tarball includes runtime modules, templates, adapters, examples, installer, and credential script while excluding tests.

## Required Human or External Gates

1. Rotate the Agnes key exposed in chat, then store the replacement with `installer/store-agnes-credential.ps1`; never reuse the exposed key.
2. Run a real Agnes authenticated generation only after rotation and confirm account quota and current terms.
3. Obtain contracts and implement official APIs before enabling Freepik/Magnific, MotionElements, Shutterstock, Vecteezy, Storyblocks, Getty/iStock, or Adobe Stock.
4. Resolve Coverr API-use terms and perform asset-level NASA promotional-use review before enabling either provider.
5. Archive current official Pexels/Pixabay license pages and complete per-asset legal/publication review.
6. Perform human visual and listening review on a real licensed/Agnes output; the synthetic E2E frames are pipeline fixtures, not aesthetic approval.
7. Use an independently human-labeled timing sample before claiming measured word-timestamp error at or below 120 ms; the current metric is Whisper timing resolution.
